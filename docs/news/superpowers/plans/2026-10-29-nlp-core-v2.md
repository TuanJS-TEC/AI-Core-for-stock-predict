### Task 2: Linker bỏ mention địa danh, có đo lường

**Files:**
- Modify: `nlp_module/entities.py`, `nlp_module/evaluate.py`, `nlp_module/cli.py`

**Interfaces:**
- Produces: các regex `_LANDMARK_SFX`, `_LOC_PREP`, `_FRAUD_CTX` lấy **nguyên văn từ spec §2.2**, cùng
  `_CORP_CTX = re.compile(r"\bCTCP\b|cổ\s+phiếu|chủ\s+đầu\s+tư", re.I)`.
- Produces: `Linker(rows, landmarks=True, fraud=True)`. Hai cờ chỉ dùng cho phép đo; giá trị mặc định là hành vi
  production. Task 3 dùng cờ `fraud`.
- Luật địa danh trong `find()`: với alias không phải `symbol`, bỏ mention khi đồng thời
  `_LOC_PREP.search(text[max(0, s-25):s])`, `_LANDMARK_SFX.match(text[e:e+40])` và
  **không** có `_CORP_CTX.search(text[max(0, s-100):e+100])`.
- Produces: `evaluate.link_changes(c, old: Linker, new: Linker, stream: str) -> collections.Counter`. Với mỗi
  `annotation_sample` của stream, chạy `link(title, normalized_text, published_at)` của cả hai linker và lấy Link của
  `target_entity_id`. Khóa Counter là `(nhóm, thay đổi)`:
  - `nhóm` là `sentiment_label` khi đã gán nhãn, nếu không thì `annotation_status` (`skipped`/`unclear`).
  - `thay đổi` ∈ `same`, `dropped` (mất link), `demoted` (`direct` → khác), `other`.
- Produces: CLI `link-check --rule landmarks|fraud --stream dev`, in Counter, so `Linker(rows, **{rule: False})` với
  `Linker(rows)`.
- **Luật giữ (cố định trước khi đo, chỉ dùng dev):** giữ luật khi, trong các mẫu dev mà luật làm thay đổi, số mẫu

### Task 4: Baseline v2: đặc trưng, trọng số lớp, C, hệ số prior

**Files:**
- Modify: `nlp_module/sentiment/baseline.py`
- Test: `tests/test_baseline.py` (mới)

**Interfaces:**
- Produces: `train(texts, labels, version, features="v1", weights="balanced", C=1.0, prior=(1.0, 1.0, 1.0)) -> Baseline`.
  Gọi với tham số mặc định phải ra đúng pipeline v1 hiện tại.
  - `features="v1"`: `TfidfVectorizer(ngram_range=(1, 2), sublinear_tf=True, lowercase=True)` (như hiện tại).
  - `features="v2"`: `FeatureUnion` gồm word `TfidfVectorizer(ngram_range=(1, 3), min_df=2, max_df=0.90, sublinear_tf=True, lowercase=True)`
    và `TfidfVectorizer(analyzer="char_wb", ngram_range=(3, 5), min_df=5, sublinear_tf=True, lowercase=True)`.
  - `weights="balanced"` → `class_weight="balanced"`; `weights="sqrt"` → `class_weight={c: (N / n_c) ** 0.5}`, với N
    là số mẫu train và n_c là số mẫu của lớp c.
- Produces: `Baseline(model, version, prior=(1.0, 1.0, 1.0))`. `prior` theo thứ tự `LABELS`. `predict` nhân xác suất
  từng lớp với prior rồi chuẩn hóa tổng về 1; lớp vắng trong train vẫn ra 0. `save` ghi `(model, version, prior)`;
  `load` nhận cả tuple 2 phần tử (bundle v1) lẫn 3 phần tử.
- Produces: `class_weights(labels, kind) -> dict | str` (dùng chung cho train và test).

- [ ] **Step 1: Viết test (thất bại)**

```python
import joblib, pytest
from nlp_module.sentiment.baseline import Baseline, class_weights, train

X = ["lãi tăng mạnh", "lợi nhuận tăng", "họp cổ đông", "công bố thông tin", "lỗ nặng", "thua lỗ kéo dài"] * 3
Y = ["positive", "positive", "neutral", "neutral", "negative", "negative"] * 3

def test_sqrt_weights():
    w = class_weights(["neutral"] * 8 + ["negative"] * 2, "sqrt")
    assert w["neutral"] == pytest.approx((10 / 8) ** 0.5) and w["negative"] == pytest.approx((10 / 2) ** 0.5)
    assert class_weights(Y, "balanced") == "balanced"

def test_prior_shifts_probabilities_and_keeps_sum(tmp_path):
    b = train(X, Y, "t")
    p0 = b.predict(["họp cổ đông"])[0]
    b.prior = (3.0, 1.0, 1.0)
    p1 = b.predict(["họp cổ đông"])[0]
    assert sum(p1) == pytest.approx(1.0) and p1[0] > p0[0]

def test_v1_two_tuple_bundle_still_loads(tmp_path):
    b = train(X, Y, "v1")
    joblib.dump((b.model, b.version), tmp_path / "old.joblib")
    old = Baseline.load(tmp_path / "old.joblib")
    assert old.prior == (1.0, 1.0, 1.0) and old.predict(["lỗ nặng"]) == b.predict(["lỗ nặng"])

def test_v2_features_train_and_roundtrip(tmp_path):
    b = train(X, Y, "v2", features="v2", weights="sqrt", C=3.0, prior=(1.5, 1.0, 1.2))
    b.save(tmp_path / "b.joblib")
    assert Baseline.load(tmp_path / "b.joblib").predict(X[:2]) == b.predict(X[:2])
```

### Task 5: Chọn cấu hình v2 trên dev và huấn luyện hai bundle

**Files:**
- Modify: `nlp_module/sentiment/baseline.py` (`fit_prior`), `nlp_module/cli.py` (lệnh `select-baseline`)
- Test: `tests/test_baseline.py`
- Data: `data/baseline_v2_selection.txt`, `data/models/baseline-v2-cal.joblib`, `data/models/baseline-v2.joblib`

**Interfaces:**
- Consumes: `train(...)`, `Baseline.prior` từ Task 4; `annotate.dataset(c, "dev")`; `evaluate.metrics`.
- Produces: `fit_prior(probs, labels, grid=(1.0, 1.25, 1.5, 1.75, 2.0, 2.5, 3.0)) -> tuple[float, float, float]`.
  Thử mọi `(a_pos, 1.0, a_neg)` trong `grid × grid`, chọn macro-F1 cao nhất. Hòa thì chọn tổ hợp có
  `abs(log a_pos) + abs(log a_neg)` nhỏ nhất, hòa tiếp thì lấy tổ hợp đầu tiên theo thứ tự lặp.
- Produces: CLI `select-baseline`:
  1. Dev có nhãn, sắp theo `published_at`: 80% đầu là train, 20% cuối là val.
  2. Thử lưới `features ∈ {"v1","v2"} × weights ∈ {"balanced","sqrt"} × C ∈ {0.3, 1.0, 3.0, 10.0}` (16 cấu hình),
     huấn luyện trên train, đo macro-F1 trên val. Chọn macro-F1 cao nhất; hòa thì chọn C nhỏ hơn.
  3. Với cấu hình đã chọn, `fit_prior` trên xác suất val của mô hình twin (train 80%).
  4. Lưu twin (80%, cấu hình + prior) thành `data/models/baseline-v2-cal.joblib`, version `baseline-tfidf-lr-v2-cal`.
     Lưu bản production (toàn bộ dev, cấu hình + prior) thành `data/models/baseline-v2.joblib`, version `baseline-tfidf-lr-v2`.
  5. Ghi bảng 16 cấu hình, cấu hình chọn, prior chọn, cùng macro-F1 và per-class recall trên val (trước/sau prior) vào
     `data/baseline_v2_selection.txt`.

from nlp_module.sentiment.baseline import fit_prior

def test_fit_prior_recovers_underweighted_positive():
    # positives scored just under neutral: a_pos > 1 flips them, negatives untouched
